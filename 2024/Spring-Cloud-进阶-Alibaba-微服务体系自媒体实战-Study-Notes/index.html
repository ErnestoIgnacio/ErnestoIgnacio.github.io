慕课网实战课程Spring Cloud 进阶 Alibaba 微服务体系自媒体实战学习笔记


第1章 课程导学

为什么要做这门课程

  • 打怪升级，斩获Offer
  • 通过项目融合技术，深度学习
  • 场景化演练
  • 迅速提升工作经验
  • （单纯的学习理论技术知识，很容易忘记，通过实战、写代码来加深印象和代码编程呢个、工程能力）


课程安排

  • 与企业一致的开发思维（贴合企业实战开发、贴合企业主流技术栈，提供主流解决方案）

  • 手把手教学演练（联调、调试、测试，整个流程细致入微）

  • 从架构师角度演变项目，引入各个技术点

    • 从架构师角度慢慢演变
    • 整合分布式中间件到项目中

  • 迭代与里程碑



重点功能技术分析

  • Redis：分布式会话、session共享、单点登录、防刷、计数
  • Fastdfs+Nginx/OSS/GridFS：搭建分布式文件系统、单文件/批量上传、人脸隐私保护拦截
  • Maven：项目构建、聚合、分层、架构设计、面向对象
  • 阿里AI：人脸对比、文本/图片自动审核、短信
  • RabbitMQ：安装配置、异步解耦、延迟消息
  • SpringCloud ：业务分而治之、可伸缩、可扩展、接口服务化
  • Freemarker：构建模板页，实现页面静态化

第2章 架构后端项目

前后端分离设计模式探讨

  • 传统JavaWeb开发，所有的数据和项目部署都是在同一个节点，耦合度相当大
  • 前后端页面交互，异步通信，前后端解耦，并行开发，提高效率，提高项目的可扩展性


虚拟域名绑定与使用

  • 实际开发中，我们可以借助SwitchHosts工具，来对ip进行虚拟域名绑定，方便开发（开发机的ip可能不固定）


数据库选型和数据导入

  • MySQL 5.6/5.7
  • MySQL 8.0（需要注意MySQL版本不同，依赖的驱动就不一样）
  • MariaDB
