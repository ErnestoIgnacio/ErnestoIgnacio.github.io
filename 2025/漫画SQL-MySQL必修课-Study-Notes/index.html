章节2: 数据库的相关概念

数据

数据的概念

  • 侠义数据（Data）：指的是描述事物的一种符号（更多的是指数字）
  • 广义数据（Data）：可以有多种形式（数字、文字、图形、图像、声音等）

数据的特点

  • 与其语义不可分


数据库

概念

  • 数据库是指存放数据的仓库

数据库的作用

  • 存储数据
  • 检索、访问、操作数据
  • 生成新数据（通过组合分析，可以生成新的有用信息）

数据库的特性

  • 数据库由数据表、视图、存储过程等组成
  • 表中的数据是按行存储的

信息冗余带来的问题

  • 占用空间
  • 新增、修改变得麻烦、困难（可能出现更新异常）


数据库管理系统（DBMS）

作用

  • 操纵和管理数据库的大型软件
  • 可建立、使用和维护数据库
  • 对数据库进行统一管理和控制，保证数据库的安全新和完整性


数据库管理员（DBA）

  • 建立、管理、维护数据库的人


数据模型

  • 将现实世界的数据转换成机器世界的数据的过程叫做建模
  • 数据操作的几种类型：CRUD
  • 数据的完整性约束
    • 是一组规则，这组规则对数据起制约作用
    • 用来限定数据的状态，以保证数据的正确、有效、相容
  • 数据的完整性约束（在关系模型中，任何关系必须满足这三种约束）
    • 实体完整性约束
      • 表中不能存在相同的记录
      • 每条记录都要有一个不重复的主键（如果字段有重名且无法区分，则需要加入主键）
      • 主键不能为空
    • 域完整性
      • 向表中添加数据时，要限制向表中输入值的范围，保证输入有效（例如：性别必须是男或女，身份证必须是18位，考试分数必须是0~100）
    • 参照完整性
      • 当一个表引用了另一个表中的某些数据时，相关字段的值要保持一致（外表中的外键值必须是主表中存在的值）
