Introduction to Gin Web Framework

  • Gin 是一个用 Go(Golang) 编写的 HTTP web 框架

  • 具有高性能的优点，其性能比普通HTTP web 框架(httprouter)提高了近40倍

  • gin设计简单，性能高效，无论是简单还是复杂的web系统，用起来都非常顺手

  • 入门容易

  • 可以通过gin构建很丰富的应用

  • Go语言常用web框架

    • Gin
    • buffalo
    • beego
    • echo
    • iris
    • revel
