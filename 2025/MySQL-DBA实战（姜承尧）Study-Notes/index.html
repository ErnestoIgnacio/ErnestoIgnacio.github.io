MySQL 5.7 与 MySQL 5.6 的安装差异

（1）初始化数据库的命令不同

（2）初始密码不同

  • MySQL5.6安装后默认没有密码
  • MySQL5.7安装后初始密码在error.log日志中
  • 如果希望MySQL5.7安装初始化的时候表现跟MySQL5.6一样-没有密码，则可以在初始化数据库的语句中 bin/mysqld --initialize --user=mysql，把 --initialize 替换成 --initialize-insecure。（可以通过 mysqld --verbose --help | less 查看到两个参数的说明）

（3）设置密码的方式不同



常用命令



默认数据库介绍

  • information_schema
    • 数据架构表（元数据表）
  • mysql
    • 记录用户登录信息相关的表
  • performance_schema
    • 记录数据库的性能监控相关信息表
  • sys
    • MySQL5.7新增的数据库，将performance_schema的复杂表整理成的视图存储在该库
  • test
    • MySQL5.6版本有该库，5.7版本没有该库


MySQL跨版本升级

5.6（或5.x）升级5.7

（1）准备好两个版本的安装包，并初始化

（2）停止数据库，将软链接从低版本指向高版本，然后重启数据库

（3）重启后日志中会有报错，可以执行mysql_upgrade -uroot -p命令来升级表

MySQL的配置参数



查看mysql的参数，当前配置的值

命令 说明
SHOW [GLOBAL |SESSION] VARIABLES [LIKE ‘pattern’ |WHERE expr] 查看变量，可根据like进行过滤
SET [GLOBAL|SESSION] VARIABLES = xxx 修改global或session的参数


MySQL的参数分类

  • 从作用域上可分为global和session
    • seesion：只对当前这一个连接有效
    • global：全局有效
  • 从类型上又可分为可修改和只读参数
    • 用户可在线修改非只读参数
    • 只读参数只能通过配置文件修改并重启
    • 所有参数的修改都不持久化
